### FASE 2.1 — DM with HLN correction
Touched: `prediction/naive_baseline.py` only. `diebold_mariano_test`
now returns the HLN-corrected statistic DM* and a two-sided p-value
from the t_{n-1} distribution. For h=1 this is numerically very close
to the old DM/normal version; for h>1 the test becomes noticeably more
conservative (smaller |DM*|), as the formula prescribes.

**Behavior impact**: DM tables (Tabel 4.12, 4.13, H4 sufficiency) use
the corrected test. Existing analyses that quoted old DM values from
prior runs are no longer the right reference — recompute from
`THESIS_RESULTS_20260523/`.

### FASE 2.2 — CSA objective = RMSE on log-return
Touched: `prediction/utils/forecast_utils.py` (one function). CSA
fitness was MAPE on log-return, which is unstable when the target
crosses zero. Now RMSE on the same log-return target — aligned with
XGBoost's squared-error training loss and finite for all normal folds.

**Behavior impact**: CSA may pick different hyperparameter regions than
prior runs. Re-run required to see the effect. Tabel 4.11 (CSA winners)
in this branch was generated with the new objective.

### FASE 2.3 — BASE = true library defaults
Touched: `prediction/utils/forecast_utils.py` (one constant). `BASE_PARAMS['xgboost']`
is now `{}`. `create_sklearn_model('xgboost', {})` returns `XGBRegressor`
with `random_state=42` and **no other custom hyperparameter** — so the
implicit XGBoost defaults (n_estimators=100, max_depth=6, learning_rate=0.3,
subsample=1.0, colsample_bytree=1.0, min_child_weight=1) take effect at
fit time. Custom `eval_metric=_xgb_mape_metric` and `early_stopping_rounds=50`
are gone from the BASE path. CSA is unchanged (its own param spaces).

**Behavior impact**: BASE results in Tabel 4.10 reflect the actual
default model. Numbers will differ from the pre-2026-05-23 BASE rows
in `prediction/output_horizons/**/horizon_summary_Daily_testing.csv`
(which were tuned-looking). Treat the old per-horizon CSVs in
`output_horizons/` as overwritten by the FASE 4 run.
