Flowchart — P5 Forecast Precompute

Control-flow proses 5.0 (DFD Level 2: 5.1 → 5.2 → 5.3 → 5.4 → 5.5). Loop h × anchors + forward fan + try/except wrapper.

Diagram

Lima sub-proses berurutan dengan try/except wrapper di _step_precompute agar kegagalan inferensi tidak membatalkan langkah 1–4. Loop nested: for h in 1..7 × for anchor in window_idx (~365 anchors). Cabang nyata: load model gagal, feature mismatch, NaN guard, target_idx clip ke T+1 (konvergensi trail), forward-fan kedua loop.

    Q1{"df.empty?"}:::decision
    EmptyRet(["RETURN payload kosong

    LW["5.2a load_winners()
(← D7 winners.json, lru_cache size=1)"]:::process

    %% Rolling trails loop (5.2).
    OuterH["5.2b for h in 1..max_horizon (=7):"]:::process
    Q2{"winners[h] ada?"}:::decision
    SkipH["log warn → next h"]:::process
    LM["5.2c load_model(tag, h, 'csa')
(joblib model.pkl + scaler.pkl + meta.json;
 lru_cache size=64)"]:::process
    Q3{"load model gagal?"}:::decision
    InnerA["for i in window_idx:"]:::process
    Q4{"target_idx = i+h
> last_idx + 1?"}:::decision
    SkipA["skip (konvergensi T+1)"]:::process
    Sel["X = select_feature_matrix(row, feature_cols)"]:::process
    Q5{"ValueError feature mismatch?"}:::decision
    LogOnce["log mismatch sekali → skip anchor"]:::process
    Q6{"isnan(X).any()?"}:::decision
    Sk2["skip"]:::process
    Pred["log_ret = model.predict(scaler.transform(X))
pred_price = anchor_close * exp(clip(log_ret, -10, 10))
append titik {anchor_date, anchor_price,
  predicted_date, predicted_price, log_return}"]:::process
    InnerEnd{"window selesai?"}:::decision
    TrailA["append trail {horizon, tag, config, points[]}"]:::process
    OuterEnd{"semua h selesai?"}:::decision

    %% Forward fan (5.3).
    Fan["5.3 forward fan: anchor = last_idx
future_days[0..max_horizon-1] = next_trading_day× max_h"]:::process
    FanLoop["for h in 1..7:"]:::process
    Q7{"winners[h] ada
+ load_model OK
+ X bukan NaN?"}:::decision
    FanSkip["skip h"]:::process
    FanPred["log_ret = model.predict(scaler.transform(X))
pred_price = anchor_close * exp(clip(log_ret, -10, 10))
append forward_fan {h, tag, config,
  anchor_date, predicted_date=future_days[h-1],
  predicted_price, log_return}"]:::process
    FanEnd{"fan loop selesai?"}:::decision

    %% Persistence (5.4 + 5.5).
    Flat["5.4a _flatten_trails(trails) → points[]
{frequency='Daily', horizon, tag, config,
  anchor_date, anchor_price, predicted_date,
  predicted_price, log_return}"]:::process
    Q8{"points kosong?"}:::decision
    SkipW(["log warn + RETURN 0"]):::error
    W1["5.4b write_forecasts(db, points)
→ D8 (doc id = Daily_h<h>_<anchor>,
  batch=100, 1s pause)"]:::process
    W2["5.5a write_forecast_meta(db, meta_dict)
→ D9 forecast_meta/Daily
(payload_json bundle winners/configs/
  metrics/horizons/forward_fan/tag_to_config)"]:::process
    Del["5.5b _delete_legacy_doc(db)
→ hapus forecasts/latest jika ada"]:::process
    End(["RETURN n (count points written)"]):::startend
    Catch(["except: log error + RETURN False
(scheduler steps 1–4 tetap commit)"]):::error
