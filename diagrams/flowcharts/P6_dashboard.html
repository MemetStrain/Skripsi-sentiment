Request HTTP masuk → URL dispatcher → routing ke salah satu dari empat view berdasarkan path. Setiap view membaca Firestore yang relevan lalu render template (HTML) atau JsonResponse (JSON). Cabang nyata: Firebase belum init pada dashboard (fallback ke _empty_dashboard_ctx), forecast_meta/Daily missing pada forecasts_api (503), forecasts collection kosong (503), exception fallback (500), dan sentiment filter aktif pada news.
