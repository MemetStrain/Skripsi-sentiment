Structure Chart — P2 News Acquisition

Dekomposisi modul proses 2.0 (DFD L2: 2.1–2.6). 6 sub-proses; urutan eksekusi: kiri → kanan.

← DFD Structure Charts (Index) Flowcharts (Index) Pseudocodes (Index) P1 Price P2 News P3 Sentiment P4 HMM P5 Forecast P6 Dashboard

Pendahuluan

Proses P2 — News Acquisition berjalan pada langkah 2 dan 3 run_daily_update(). Akar adalah gabungan _step_news(paths) (main.py:260, scraping + CSV) dan reconcile_news(db, articles) (reconcile.py:85, mirror ke D2). Enam sub-proses dieksekusi kiri → kanan: 2.1 cek kesegaran → 2.2 scrape MPOB → 2.3 preprocess teks → 2.4 skor FinBERT-Tone → 2.5 append CSV → 2.6 reconcile ke Firestore. Sub-proses 2.4 menggunakan model yiyanghkust/finbert-tone secara lokal (title-only, batch 16) — tidak ada inferensi di jalur request website.
