Structure Chart — P4 HMM State Decoding

Dekomposisi modul proses 4.0 (DFD L2: 4.1–4.5). 5 sub-proses; urutan eksekusi: kiri → kanan. Parameter HMM beku (D5) — tidak pernah refit saat runtime.

← DFD Structure Charts (Index) Flowcharts (Index) Pseudocodes (Index) P1 Price P2 News P3 Sentiment P4 HMM P5 Forecast P6 Dashboard

Pendahuluan

Proses P4 — HMM State Decoding berjalan pada langkah 4 run_daily_update(). Entry point adalah update_hmm_states(db) (hmm_updater.py:157). HMM tidak pernah di-refit saat runtime — parameter beku dipublikasikan satu kali offline oleh migrate_hmm_to_firestore.py dan disimpan di D5 (hmm_models/Daily). Algoritma dekoding menggunakan online forward filter (bukan Viterbi) sehingga state historis tidak berubah setiap hari. Lima sub-proses dieksekusi kiri → kanan: 4.1 load param beku → 4.2 load harga → 4.3 bangun fitur HMM → 4.4 dekode state → 4.5 write ke D4.
