Structure Chart — P6 Dashboard Web

Dekomposisi modul proses 6.0 (DFD Level 1 & Level 2) — Django + 4 view read-only dari Firestore. Tanpa modul ML di jalur request. Urutan view = urutan url pattern.

Pendahuluan

Proses P6 — Dashboard Web dimulai dari perintah python manage.py runserver (pada Vercel: WSGI handler di website/vercel_wsgi.py) yang menyalakan Django. Setiap HTTP request dari Pengunjung di-route oleh web/urls.py ke salah satu dari empat fungsi view. Karena rantai boot Django adalah infrastruktur framework, bukan modul aplikasi, akar diagram disederhanakan menjadi satu node tunggal (lihat tabel “Modul Boot & Dispatch”). Empat sub-proses 6.1–6.4 adalah view publik read-only, dengan urutan di diagram = urutan url-pattern (/, /api/forecasts/, /news/, /about/) — kiri ke kanan.

Tidak ada modul ML (joblib, numpy, pandas, xgboost) yang di-impor oleh website/web/*.py. Trail forecast diproduksi oleh proses 5.0 (P5) di scheduler dan dipersisten ke koleksi forecasts (D8) + dokumen forecast_meta/Daily (D9); P6 hanya membacanya.

Catatan Implementasi

  • Akar = CLI tunggal: rantai Django boot ditampilkan sebagai satu node tunggal pada diagram; detail boot ada di tabel di atas.
  • Tanpa autentikasi: seluruh endpoint publik read-only.
  • forecasts_api read-only: hanya membaca forecast_meta/Daily + koleksi forecasts. Tidak ada joblib.load, model XGBoost, scaler di jalur request. Filter predicted_date & horizon dilakukan di Python untuk menghindari kebutuhan composite index Firestore.
  • Inferensi dipre-komputasi: trail forecast diproduksi oleh proses 5.0 (scheduler/precompute_forecasts.py) yang memanggil prediction/inference.py::compute_forecast_trails dan menulis hasilnya ke D8 + D9. Sebelumnya algoritma yang sama berada di website/web/predictor.py; kini direlokasi ke prediction/inference.py agar bisa di-share antara scheduler precompute dan (hipotetis) jalur batch lain.
  • Composite-index avoidance: news men-fetch semua doc lalu sort di Python; forecasts_api juga men-stream seluruh koleksi forecasts lalu filter di Python.
  • Edge-caching: news di-decorate dengan @cache_control(public=True, s_maxage=3600, max_age=60) agar Vercel CDN menyimpan respons selama 1 jam — berita hanya berubah saat scheduler jalan (~harian).
  • Data store yang dibaca P6: D1 (daily_prices), D2 (news_articles), D3 (sentiment_aggregates), D4 (hmm_states), D8 (forecasts per-point), D9 (forecast_meta/Daily). Tidak ada write apapun.
