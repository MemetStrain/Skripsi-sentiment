Structure Chart — P5 Forecast Precompute

Dekomposisi modul proses 5.0 (DFD Level 1 & Level 2) — inferensi XGBoost lokal (h=1..7) + write per-titik ke Firestore. Urutan eksekusi: kiri → kanan.

Pendahuluan

Proses P5 — Forecast Precompute adalah fase terakhir scheduler harian. Inferensi XGBoost tidak dijalankan di jalur request website (Vercel) — terlalu berat untuk serverless functions — melainkan dipre-komputasi secara lokal lalu dipublikasikan ke Firestore. Akar struktur chart ini adalah _step_precompute(db) di scheduler/main.py:303, wrapper try/except yang men-delegate ke precompute_forecasts.precompute_and_write(db) (scheduler/precompute_forecasts.py:106). Modul anak dieksekusi kiri → kanan: 5.1 import inference & build frame → 5.2 rolling trails + forward fan (compute_forecast_trails) → 5.3 flatten + write forecasts → 5.4 write forecast_meta + hapus legacy doc.

Sumbu waktu eksekusi: kiri → kanan. Try/except di _step_precompute menjamin kegagalan inferensi tidak membatalkan langkah 1–4 (Price/News/Reconcile/HMM) yang sudah commit. Full recompute (bukan incremental): setiap run meregenerasi seluruh window 365 anchor × 7 horizon — doc ID deterministik Daily_h<h>_<anchor> membuat write idempoten dan self-healing.

Catatan Implementasi

  • Full recompute, bukan incremental: setiap run regenerasi window 365 hari penuh × 7 horizon = ~2500 doc per-titik. Doc ID deterministik (Daily_h<h>_<anchor>) membuat write idempoten dan self-healing — skipped run atau externally-mutated doc langsung dikoreksi pada run berikutnya.
  • Try/except wrapper: _step_precompute membungkus orchestrator agar kegagalan inferensi (mis. model missing) tidak membatalkan langkah 1–4 yang sudah commit ke Firestore.
  • Konvergensi T+1: trail per-horizon men-clip target_idx > last_idx + 1, sehingga prediksi terakhir tiap horizon mendarat di hari trading berikutnya (T+1) — semua 7 trail bertemu di titik shared.
  • Forward fan: selain trail rolling yang konvergen di T+1, ada satu prediksi per horizon dari anchor terakhir T → T+1..T+7 (digambarkan sebagai garis fan di dashboard).
  • Clip log-return: np.clip(log_ret, -10, 10) sebelum exp mencegah overflow numerik pada outlier ekstrim model.
  • Legacy doc cleanup: _delete_legacy_doc menghapus dokumen forecasts/latest (jalur lama single-doc) agar tidak menyajikan payload basi ke website.
  • Cache lru: load_winners (size=1) dan load_model (size=64) sehingga joblib.load tidak dipanggil ulang per anchor.
